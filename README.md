# Scoop bucket for QNotch

[QNotch](https://qnot.ch) is a small notch at the top of your desktop for music, system stats, files, clipboard history, and coding agents.

```powershell
scoop bucket add qnotch https://github.com/Somafet/scoop-bucket
scoop install qnotch/qnotch
```

Update with `scoop update qnotch`. This adds the `qnotch` command and a Start menu shortcut.

`bucket/qnotch.json` is updated by the [QNotch release workflow](https://github.com/Somafet/qnotch/blob/main/docs/releases.md#winget-and-scoop) after each Windows release. Report problems in the [QNotch repository](https://github.com/Somafet/qnotch/issues).
